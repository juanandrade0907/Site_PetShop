# 🐾 Petshop do Cachorrão — Site Web (HTML & CSS)

📌 Sobre o Projeto
---

Este projeto foi desenvolvido como parte das atividades acadêmicas do curso de Ciência da Computação, com o objetivo de aplicar conceitos de desenvolvimento web front-end e estruturação de páginas responsivas utilizando HTML5 e CSS3.

O trabalho consiste na criação e estilização de um site completo para o **Petshop do Cachorrão**, contemplando seções de apresentação dos serviços, produtos, galeria visual e informações de contato.

🛠️ Tecnologias Utilizadas
---

- **HTML5** — Linguagem de marcação utilizada para a estruturação semântica do conteúdo da página.
- **CSS3** — Linguagem de estilo utilizada para o design visual, estilização, layout flexível e responsividade.

📁 Estrutura de Arquivos
---

O projeto é composto pelos seguintes arquivos e diretórios:

- `index.html` — Estrutura e conteúdo principal da página web.
- `css/style.css` — Folha de estilos responsável pelo visual e layout do site.
- `img/` — Diretório contendo as imagens e recursos visuais utilizados na interface.

🎨 Conceitos Aplicados
---

Durante o desenvolvimento do projeto, foram trabalhados conceitos fundamentais de Web Front-End:

- Estruturação semântica em HTML5 (`<header>`, `<nav>`, `<main>`, `<section>`, `<footer>`).
- Organização de layouts modernos e flexíveis com Flexbox.
- Estilização de menus de navegação, botões e elementos interativos.
- Aplicação de hierarquia visual, tipografia e paletas de cores.
- Vinculação correta de arquivos externos de estilo (`style.css`) e mídias visuais (`.jpg`/`.png`).

🎯 Objetivo Acadêmico
---

Consolidar os conhecimentos introdutórios em desenvolvimento web front-end, desenvolvendo habilidades práticas na criação de páginas estáticas organizadas, semânticas e visualmente atraentes.
